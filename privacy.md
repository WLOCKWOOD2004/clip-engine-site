# Clip Engine privacy policy

Last updated: 21st November 2026

Clip Engine is a private, single-user tool. Only its owner signs in to it, with their own Google account, to manage their own YouTube channel.

**What it accesses.** With the owner's consent, Clip Engine uses the YouTube Data API to upload videos to the owner's channel and to read that channel's own video details and view counts.

**What it stores.** The sign-in token and the view counts are stored only on the owner's own computer. Nothing is sent to any other server, sold, or shared with anyone.

**No other users.** Clip Engine does not collect data about anyone else. It has no accounts, no analytics and no advertising.

**Removing access.** Access can be removed at any time at https://myaccount.google.com/permissions, and deleting the token file removes the stored sign-in.

Clip Engine's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
